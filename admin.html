Админ-панель · регионы и маршрутизация

Регионы (виловят → транк · очередь · агенты)

Outbound: префикс подставляется к номеру, чтобы FreePBX выбрал транк региона через Outbound Route. Inbound: когда на один DID звонят контакты разных регионов, звонок направляется во «Вх. назначение» по номеру звонящего (то, что FreePBX сам по DID сделать не может).

Тест входящей маршрутизации

Введите номер звонящего (как придёт CallerID) и, при желании, DID — увидите, в какое назначение уйдёт звонок. Тот же ответ вернёт дайлплан.

Синхронизация контактов из 1C

Контакты подтягиваются из 1C автоматически каждую минуту — по одному запросу на каждый регион, у которого задана Область (1C). Телефон сохраняется в виде 9-значного номера (напр. 909090774): +998, пробелы и дефисы отбрасываются. Ручная загрузка Excel больше не нужна.

Контакты по региону

Новый регион

Известный звонящий уходит по своему номеру во «Вх. назначение» (очередь/ринг-группа, где сидят агенты). Неизвестный — в этот IVR, выбранный по DID, на который он позвонил (у каждого транка свой IVR). Если IVR пуст — используется общий DEFAULT_TARGET из .env.

Область (1C) — из этого справочника (поле «Область» в 1C) контакты этого региона подтягиваются автоматически каждую минуту. Если не выбрано — регион не синхронизируется.
